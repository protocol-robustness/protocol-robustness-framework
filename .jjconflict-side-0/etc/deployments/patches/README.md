# prf-evm configuration hardening

`prf-evm-configuration-hardening.patch` targets prf-evm revision
`4b6b6ed159762c88099c96d4dafd635ab99470ea`. The requested
`prf-evm-config-bounded-current` ref was unavailable; equivalence to that ref
has not been established.

The prf-evm checkout is outside this session's writable roots. The changes were
implemented and tested in `/tmp/prf-configuration-hardening`; this patch
preserves the complete changes in the PRF workspace. The original prf-evm
checkout has not been modified. `git apply --check` passes against that checkout.

The patch adds executor instance checks at admission construction and at every
admission, checks initial authority-root continuity before genesis sealing,
corrects registry encoding comments, and includes regression tests and the
shared PRF/Solidity fixture corpus. It preserves registry v1 encoding and
receipt identity semantics. The capital test rejects use of a receipt for a
different operation and verifies one-time consumption.

From a writable prf-evm checkout at the target revision:

```bash
git apply --check /path/to/prf/etc/deployments/patches/prf-evm-configuration-hardening.patch
git apply /path/to/prf/etc/deployments/patches/prf-evm-configuration-hardening.patch
forge test --match-contract 'PrfGenesisTest|PrfStatementAdmissionTest|PrfRegistryEquivalenceTest|PrfAssuredOperationConsumerTest|SourceBoundProRataAssuranceV2Test|PrfStatementAdmissionRealProofTest|PrfSourceBoundEntitlementAdmissionRealProofTest'
```

The seven focused suites passed in the writable copy (85 tests), including
real Groth16 proof verification. Fixture roots were also independently recomputed by PRF tests.
The JSON fixture is generated by
`clojure -M -m scripts.deployment.registry-equivalence` in PRF; after intentional
fixture changes, update the Solidity copy and rerun both suites.

This patch does not implement on-chain canonical authority transition
enforcement, authenticate verifier runtime deployments, authenticate owner
approval, or execute a new governed Gate E deployment. Those remain explicit
requirements before claiming bounded local qualification.
