# Derived coordinates and nominal evidence attribution

Three operations retain separate meanings and canonical families:

| Operation | Artifact | Question |
| --- | --- | --- |
| Structural definition diff | `research-definition-diff.v1` | Did the frozen specification change within the supported diff vocabulary? |
| Semantic analysis comparison | `research-analysis-comparison.v1` | Are scoped observations equal, different, missing or not comparable? |
| Numeric differential | `research-coordinate-interaction.v1`, wrapped by `coordinate-derived-result.v1` | What exact contrast follows from compatible numeric observations? |

`derived-coordinate/relation-family` classifies supported schemas; it does not
validate their bodies. Existing definition and analysis validators remain in
charge. Analysis comparison is not subtraction. Reproduction evidence is a
separate downstream family, not a fourth numerical operator.

## One closed operator, not an algebra DSL

`derived-coordinate/derive-interaction` supports only the established integer
difference-of-differences operation. Its explicit operator contract says:

- Axes select observations; neither axis keys nor labels are subtracted.
- Both axes must explicitly permit interaction under the existing engine.
- Researcher, runner and implementation axis kinds are forbidden, even if
  someone supplies self-rooted metadata claiming they are integer/eligible.
- Accounting policy, experiment domain and outcome measure must match.
- Missing/non-comparable observations propagate without inventing zero.
- Unsupported conflicting observation states are rejected, not voted away.
- Existing checked-integer arithmetic is retained, with no implicit promotion.

The wrapper roots its operator contract, axis identities, constituent identities,
existing semantic result root, value, status and reason. It does not change the
original interaction root. Validation rederives from the exact source arguments;
a self-consistent hash alone is not admission. This slice adds no standalone
difference, distance, unit conversion or generic linear operations. Same measure
identity is the existing quantity-domain contract, not general dimensional analysis.

`link-reproduction` validates the source input, execution binding, original result
binding and downstream comparison before making an ordinary generic evidence
node. The source-projection path cannot substitute for a fresh execution. Equal
outputs from distinct implementation artifacts can remain reproduced without
merging execution identities. The existing common-valid-arithmetic-domain
comparison boundary remains applicable; the wrapper itself does not certify
universal cross-implementation equivalence.
This link accepts the existing four-observation replay input; extending it to
the dependency-closed upstream scheduler bundle is deferred, not implicitly
claimed by this wrapper.

## Anonymous researchers and attribution

`researcher-evidence-attribution.v1` binds a validated frozen researcher coordinate,
typed subject root, evidence root, declared relation and disclosure mode. It is a
small projection needed to preserve the scoped coordinate and disclosure alongside
generic evidence lineage; it is not a new evidence subsystem.

Disclosure may be identified, pseudonymous, anonymous or undisclosed. No real-world
name, credential or public plaintext is required. The exact experiment/authority-
scoped reference remains in internal lineage. An anonymous scoped reference can
still be linkable within its scope; this does not promise unlinkability or hide
the reference from anyone who can read the restricted evidence.

The projection is explicitly **declared** attribution: `reproduced` or `dissented`
does not authenticate authorship, establish actual reproduction, admit a claim or
create a vote. Actual reproduction is separately validated execution/evidence.
The frozen researcher-axis builder and authority membership rules are unchanged;
this projection does not enroll anonymous researchers or bypass eligibility.
Different references do not establish different people or organizations.

Both new projections attach through ordinary forensic evidence nodes. Attribution
nodes default to restricted visibility, while numeric derivation nodes are public.
Changing attribution changes its projection/evidence root, never the observed
semantic result. No researcher index is used as distance, weight, rank or value.

## Boundaries

No claim verification, derivation, acceptance, researcher positions, pro-rata
arithmetic, networking, incentives or runtime scheduling semantics are changed.
Further operators need their own explicit permission and comparability contracts;
being integer-valued never supplies those properties automatically.
